      教学版边界说明
      
所有操作只影响当前页面内存中的虚拟仓库。merge、rebase、revert、cherry-pick、pull 开始前要求工作区干净。默认 pull 使用合并方式。暂不支持二进制、重命名检测、文件/目录冲突、多合并基点、交互式变基、重放或摘取合并提交、强制推送及其他未列出的参数。手册中“仅供参考”的命令用于真实终端，网页不会执行。

      
git add 会把冲突文件标记为已解决，即使文件还留有冲突标记；请检查内容再继续。刷新页面会重置练习，单文件大小限制为 300 行、20000 字符。
